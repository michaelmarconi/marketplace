# Claude Code plugins by Michael Marconi

A catalog of Claude Code plugins. Add it once, then install any plugin it lists.

```bash
claude plugin marketplace add michaelmarconi/marketplace
claude plugin install <plugin>@michaelmarconi
```

Or, in Claude Code, `/plugin marketplace add michaelmarconi/marketplace`, then
`/plugin install <plugin>@michaelmarconi`.

## Plugins

| Plugin | What it is | Repository |
| --- | --- | --- |
| `agentic` | Skills for Agentic Engineering: building software with coding agents, with engineering rigour | [michaelmarconi/agentic-engineering](https://github.com/michaelmarconi/agentic-engineering) |

Each plugin lives in its own repository, which holds its documentation and takes its issues.
